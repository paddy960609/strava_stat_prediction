# strava_stat_prediction
Strava Performance Prediction
Project Overview

This project uses machine learning to analyze Strava activity data and predict endurance performance based on training metrics.

The goal is to understand which factors most strongly influence athletic performance and recovery.

Dataset

Personal Strava activity history including:

Distance
Moving Time
Average Speed
Elevation Gain
Heart Rate
Calories Burned

Technologies
Python
Pandas
NumPy
Scikit-Learn
Matplotlib
Google Colab

Workflow
Data Cleaning
Exploratory Data Analysis
Feature Engineering
Model Training
Model Evaluation

Key Questions
Can future run pace be predicted?
Which training variables most affect performance?
How much does elevation impact pace?
Does heart rate correlate with improved results?
